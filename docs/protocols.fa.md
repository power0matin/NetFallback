# یادداشت روش‌ها و پروتکل‌ها

NetFallback فقط نسخه‌های رسمی را آرشیو می‌کند؛ تونل را خودکار پیکربندی، نصب یا آزمایش نمی‌کند. تفاوت اصلی را فراموش نکن: **دورزدن فیلترینگ** یعنی ممکن است مسیر هنوز وجود داشته باشد اما شناسایی یا مسدود شود؛ **خاموشی شبکه** یعنی ممکن است خود مسیر لازم دیگر وجود نداشته باشد.

| خانواده | هدف | وابستگی یا حالت شکست مهم |
| --- | --- | --- |
| WARP / MASQUE | عبور ترافیک از سرویس WARP کلادفلر با انتقالی مانند HTTP/2 یا HTTP/3، بسته به پشتیبانی کلاینت | به هویت/کلید WARP معتبر و دسترسی به سرویس نیاز دارد. مسدودشدن مسیر مربوط به Cloudflare می‌تواند آن را متوقف کند. نصب عمومی WARP با همه گردش‌کارهای Aether/PattNG یکسان نیست. |
| SNI spoofing / fragmentation | تغییر نحوه دیده‌شدن TLS ClientHello/SNI یا مرزبندی بسته‌ها برای DPI | نتیجه به پیاده‌سازی DPI، مسیر شبکه، IP، رفتار TLS و مقصد بستگی دارد؛ مسیر فیزیکی جدید نمی‌سازد. |
| MHRV | عبور از Relay و اجزای مخصوص پروژه | ممکن است راه‌اندازی اولیه لازم باشد؛ حالت full-tunnel می‌تواند به Relay/Deployment و گاهی exit node نیاز داشته باشد. مستندات نسخه فعلی، سهمیه و مدل اعتماد را بررسی کن. |
| کانفیگ مستقیم/Fragment مبتنی بر Xray | استفاده از ترکیب پروتکل و کانفیگ برای عبور از برخی قواعد فیلترینگ | endpoint و کانفیگ ممکن است منقضی شوند؛ دانلودشدن کانفیگ ثابت نمی‌کند که روی اپراتور یا مقصد تو کار می‌کند. |
| Workers/Pages کلادفلر یا دامنه شخصی | استفاده از endpoint میزبانی‌شده در صورت دسترسی و سازگاری با پروژه و شرایط ارائه‌دهنده | به دسترسی دامنه/IP/IPv6، وضعیت Deployment، محدودیت سرویس و محدودیت مقصد وابسته است. Workers و Pages قابل جایگزینی فرض‌کردن نیستند. |
| مسیرهای ویژه IPv6 | استفاده از IPv6 در صورت پشتیبانی واقعی اپراتور و مقصد | پشتیبانی باید در تمام مسیر وجود داشته باشد؛ روشن‌کردن IPv6 روی دستگاه، مسیر بین‌المللی مستقل ایجاد نمی‌کند. |

## چک‌لیست عملی

1. هر روش را پیش از بحران روی همان اپراتور ثابت یا موبایلی که به آن وابسته‌ای آزمایش کن.
2. به‌جای چند کلاینت با یک سرویس بالادستی مشترک، چند سازوکار متفاوت نگه دار.
3. فایل نصب و متادیتای Release را جدا از کانفیگ زنده ذخیره کن.
4. اگر Relay، کلید یا Deployment شخصی داری، اطلاعات راه‌اندازی را نگه دار. اسرار را رمزگذاری کن و وارد Git نکن.
5. تاریخ و شرایط آخرین آزمون را ثبت کن: اپراتور، نوع دسترسی، تاریخ، خانواده IP و نتیجه. اطلاعات شناسایی یا endpoint خصوصی را در Issue عمومی قرار نده.
6. اگر همه مسیرهای اینترنت خارجی قطع شوند، نرم‌افزار پراکسی سمت کاربر به‌تنهایی مسیر جدید ایجاد نمی‌کند.

این سند دسته‌بندی روش‌هاست، نه ادعای فعال‌بودن آن‌ها در لحظه حاضر. NetFallback اندازه‌گیری زنده اپراتورها انجام نمی‌دهد.
